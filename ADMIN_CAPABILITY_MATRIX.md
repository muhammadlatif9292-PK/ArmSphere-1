# ArmSphere — Administrative Capability Convergence Matrix

## 1. Executive Summary & Design Archaeology Findings

In accordance with the ArmSphere Product Convergence Directive, the **Flutter mobile application (`apps/mobile`)** is the single primary product. The legacy `apps/admin-web` application was audited as a reference source of business requirements, API contracts, and authorization policies—not as a UI template to copy.

### Key Curation Decisions (What Was Converged vs. Retired)

| Legacy Admin Web Pattern | Convergence Verdict | Native Flutter Architectural Replacement |
| :--- | :--- | :--- |
| **Separate Admin Web `LoginPage` (`/login`)** | **RETIRED** | Unified into ArmSphere's primary Flutter authentication flow (`WelcomeScreen` → `LoginScreen` / `RegisterScreen` → `MfaVerificationScreen`). Zero separate admin login screens. |
| **Header Mode-Switch Clutter** | **RETIRED** | Switching between **Athlete Mode** and **Admin Mode** occurs exclusively inside **Settings → Account Roles & Persona (`/settings/roles`)**. |
| **Raw Dev-Ops Worker Buttons** (`Trigger Ranking Recalc`, `Dispute SLA Sweep`, `Run Scheduled Jobs`) | **RETIRED** | Background queues and cron jobs are server-side concerns. Replaced on the mobile **Command** tab with actionable federation backlog cards and real report export tools. |
| **Desktop Data Tables & Page-Number Bars** | **REPLACED** | Reimagined as **Searchable Crystal Glass Dossier Cards** with horizontal status/province filter chips and tabular numerals. |
| **Desktop Modals & Broken `<iframe>` Embeds** | **REPLACED** | Reimagined as root-overlay **Crystal Modal Bottom Sheets (`CrystalModalSheet`)** with pinned action bars above the dock and native external media launchers. |
| **`/governance` Route Escaping the 5-Tab Shell** | **FIXED** | Previously, `app_router.dart` redirected admin roles to `/governance` outside `MainShellScreen`, hiding the bottom navigation bar. Now, Admin Mode stays 100% inside `MainShellScreen` with **5 Native Admin Dock Tabs** (`Command`, `Roster`, `Arena Ops`, `Governance`, `Dossier`). |
